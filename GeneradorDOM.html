¿Qué es el DOM?

El DOM (Document Object Model) es una representación estructurada del documento HTML. JavaScript puede acceder a sus elementos y modificarlos.

Elementos de una página HTML

Una página web puede contener diferentes tipos de elementos:

  • Encabezados y títulos.
  • Párrafos de texto.
  • Listas ordenadas y desordenadas.
  • Enlaces a otras páginas.
  • Imágenes y elementos multimedia.

Pasos para trabajar con el DOM

  1. Seleccionar un elemento HTML.
  2. Consultar sus propiedades.
  3. Crear nuevos elementos.
  4. Modificar el contenido de la página.

Ejemplo de código

Podemos seleccionar un elemento utilizando document.querySelector().

También podemos crear elementos con document.createElement().
